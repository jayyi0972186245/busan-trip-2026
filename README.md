# 釜山安心遊

手機優先的四天三夜釜山行程工具，適合與長輩一起使用。

## 使用方式

直接開啟 `index.html` 即可使用，修改會自動保存在目前瀏覽器內。

- 「每日行程」可新增、編輯、刪除景點，並一鍵開啟 Google 地圖導航
- 「行前注意事項」可分類、勾選完成、新增照片網址與相關連結
- 可直接從手機相簿選擇照片，照片會壓縮後保存在目前裝置
- 「重要資訊」可保存航班、飯店、緊急聯絡人與旅遊保險資料
- 每個景點可填寫從上一站前往的預估交通時間
- 右上角「字／放大」可切換大字模式
- 「備份資料」可備份或還原所有行程與注意事項

網站已包含安裝與離線使用設定。發布到 HTTPS 網址後，可以加入手機主畫面。

## 安全雲端同步

專案已準備 Firebase Authentication、Firestore 即時同步及資料庫安全規則：

- 每位旅伴使用自己的 Google 帳號登入
- 只有 Firestore `invites/{email}` 邀請名單內的帳號可以讀寫
- 雲端只同步每日行程與行前注意事項
- 重要資訊與手機上傳照片永遠只保存在個人裝置
- 完整資料複製分享功能已移除

啟用方式：

1. 建立 Firebase 專案，啟用 Google 登入、Firestore 與 Hosting。
2. 將 Firebase 網頁設定填入 `cloud-config.js`，並把 `cloudEnabled` 改成 `true`。
3. 在 Firestore 建立 `invites` 集合，以受邀者完整電子郵件作為文件 ID。
4. 部署 `firestore.rules` 與網站。

登入和規則可以大幅降低未授權存取，但仍無法保證零風險。受邀帳號遭盜用、旅伴自行截圖，或管理者錯誤設定規則時，資料仍可能外洩。
